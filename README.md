# SplatSpray

**Rust 用 Oxide プラグイン — テリトリーミニゲーム**

ペイントボールガンで地面を塗り合い、制限時間終了時に広い面積を確保したチームが勝利します。

---

## 概要

- **2チーム制**: 水色（Team A）vs 紫（Team B）
- **弾色でチーム自動判定**: 水色の弾 → Team A、紫の弾 → Team B
- **床面のみ対象**: 壁・天井への着弾は無効
- **5発クラスター**: 半径 2m 以内に 5 発着弾するとスプレーデカールを生成
- **非同期面積計算**: グリッドサンプリングで塗り面積をバックグラウンド計算、HUD に反映
- **参加制**: `/splatjoin` で参加登録したプレイヤーのみゲームに参加できる

---

## ゲームの流れ

1. 管理者が `/splatstart <カウントダウン秒> <ゲーム時間秒>` でゲームを開始
2. 全員にチャットで通知 → プレイヤーは `/splatjoin` で参加登録
3. カウントダウン（画面中央に数字表示）終了後ゲーム開始
4. 制限時間が経過したら終了 → 面積比率でチャット・リザルト画面に結果表示
5. リザルト画面が閉じた後、試合中のスプレーをすべて削除

---

## コマンド

| コマンド | 権限 | 説明 |
|----------|------|------|
| `/splatstart <カウントダウン> <ゲーム時間>` | 管理者 | ゲーム開始（例: `/splatstart 10 180`） |
| `/splatstop` | 管理者 | ゲームを強制終了 |
| `/splatjoin` | 全員 | ゲームへ参加登録 |
| `/splatcolorcheck` | 全員 | 持っているペイントボールガンの弾色インデックスを確認 |

---

## HUD・UI

| 表示 | タイミング |
|------|-----------|
| カウントダウン画面（全画面・黄色の数字→緑の GO!） | ゲーム開始前 |
| 上部 HUD（タイマー・チーム面積・塗り率バー） | ゲーム中 |
| リザルト画面（全画面・勝敗・面積比率・バー） | ゲーム終了後 20 秒間 |
| グローバルチャット結果報告 | ゲーム終了時に全員へ |

---

## パラメータ

| パラメータ | 値 | 説明 |
|-----------|----|------|
| `CLUSTER_RADIUS` | 2.0 m | 着弾をまとめる判定半径 |
| `HITS_TO_SPRAY` | 5 発 | スプレー発動に必要な着弾数 |
| `SCALE_NORMAL` | 5 倍 | 通常スプレーのサイズ倍率 |
| `SCALE_RARE` | 8 倍 | レアスプレーのサイズ倍率 |
| `RARE_CHANCE` | 10% | レアスプレーの出現確率 |
| `CALC_STEP` | 0.3 m | 面積計算サンプリング間隔 |
| `CALC_INTERVAL` | 5 秒 | 面積計算の実行間隔 |
| `MAX_PAINT_HISTORY` | 500 件 | 記録する最大スプレー件数 |

## 弾色インデックスの設定

ゲーム内で `/splatcolorcheck` を実行して弾色のインデックスを確認し、プラグインの `_colorSkins` / `_colorToTeam` に設定します。

| 4 | 紫   | Team B | 3700118804 |

## 既知の制限事項

- スプレーデカールの上下（重なり順）はワークショップスキンのマテリアル設定に依存するため、サーバー側からの制御は不可
- カウントダウン秒数は 3〜60 秒、ゲーム時間は 30〜600 秒の範囲にクランプされます
- 参加登録はゲーム開始コマンドのたびにリセットされます（毎試合 `/splatjoin` が必要）
