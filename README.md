# SplatSpray

**Rust 用 Oxide プラグイン — コンセプト版**

> これは Rust におけるペイントボールを使ったスプレー演出を試験的に実装した**コンセプトプラグイン**です。
> マッチメイキング・チーム・スコア管理などの機能はなく、完全なミニゲームとして遊べるものではありません。

---

## 概要

SplatSpray はペイントボールガンと連携し、近い範囲に一定数の弾が着弾すると自動でスプレーデカールを地面や壁に描画します。画面上部のゲージが塗り進捗を表示し、100% に達するとゲームクリア演出が表示されます。

---

## 機能

- **自動スプレー**: 半径 2m 以内に 5 発着弾するとスプレーデカールを自動生成
- **ランダムサイズ**: 通常は 5 倍サイズ、10% の確率でレア 8 倍サイズが出現
- **SPLAT METER**: 画面上部中央にゲージを表示。着弾・スプレーのたびに増加
- **ゲームクリア画面**: ゲージが 100% に達すると全画面演出を表示。5 秒後に自動でリセット
- 建物・プレイヤーへの着弾と地面・地形への着弾の両方を検出

---

## 必要環境

- Rust サーバー用 [Oxide / uMod](https://umod.org)
- ゲーム内でペイントボールガンが入手できること

---

## インストール

1. `SplatSpray.cs` をサーバーの `oxide/plugins/` フォルダにコピー
2. 自動でロードされます

---

## コマンド

| コマンド | 説明 |
|----------|------|
| `/splatreset` | 自分の SPLAT METER を 0% にリセット |

---

## パラメータ

| パラメータ | 値 | 説明 |
|-----------|-----|------|
| `CLUSTER_RADIUS` | 2.0 m | 着弾をまとめる判定半径 |
| `HITS_TO_SPRAY` | 5 発 | スプレー発動に必要な着弾数 |
| `SCALE_NORMAL` | 5 倍 | 通常スプレーのサイズ倍率 |
| `SCALE_RARE` | 8 倍 | レアスプレーのサイズ倍率 |
| `RARE_CHANCE` | 10% | レアスプレーの出現確率 |
| `GAUGE_PER_HIT` | +0.1% | 着弾 1 発あたりのゲージ増加量 |
| `GAUGE_PER_SPRAY` | +5% | スプレー発動時のゲージ増加量 |

---

## 既知の制限事項（コンセプト版）

- チーム・スコア・勝敗判定などのミニゲーム機能はありません
- ゲージは時間経過で減少しません
- デカールのサイズは `networkEntityScale` で適用しています。サーバーバージョンによって挙動が異なる場合があります
- 地面への着弾検出は `OnPlayerAttack` フックに依存しています
